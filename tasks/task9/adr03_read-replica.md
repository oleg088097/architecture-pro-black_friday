### <a name="_3bfxc9a45514"></a>**Контекст**

Коллекция **orders**:
```mongodb-json
{
    "_id": ObjectId, 
    "user_id": String, 
    "order_date": Date, 
    "items" : [{
        "item_id": ObjectId,
        "price": Integer
    }], 
    "status": String, 
    "total_price": Integer,
    "geo_zone": String,
}
```
Основные операции:
- Быстрое создание заказов с одновременным списанием остатков.
- Поиск истории заказов конкретного пользователя.
- Отображение статуса заказа.


Коллекция **products**:
```mongodb-json
{
    "_id": ObjectId, 
    "display_name": String,
    "category": String,
    "price": Integer, 
    "stock" : [{
        "geo_zone": String,
        "quantity": Integer
    }], 
    "attributes": JSONB
}
```
Основные операции:
- Частые обновления остатков при покупках.
- Поиск товаров по категориям и фильтрация по диапазону цен.
- Описание товара на странице продукта.


Коллекция **carts**:
```mongodb-json
{
    "_id": ObjectId, 
    "user_id": String,
    "session_id": String,
    "items": [{ "product_id": ObjectId, "quantity": Integer }],
    "status": String,
    "created_at": Date,
    "updated_at": Date,
    "expires_at": Date
}
```
Основные операции:
- Создание корзины, когда заходит гость или новый пользователь.
- Получение текущей корзины по фильтру { session_id, status:"active" } или { user_id, status:"active" }.
- Добавление или замена товара в корзине.
- Удаление товара из корзины.
- Слияние гостевой корзины в пользовательскую, если пользователь залогинится:
    - прочитать гостевую { session_id, status:"active" };
    - добавить её items в корзину { user_id, status:"active" };
    - отметить гостевую как abandoned.
- Отметка корзины как заказанной.

### <a name="_qmphm5d6rvi3"></a>**Решение**

Коллекция **orders**

| Операция                                       | Узел      | Обоснование                                                                                                                                    |
|------------------------------------------------|-----------|------------------------------------------------------------------------------------------------------------------------------------------------|
| Поиск истории заказов конкретного пользователя | Secondary | Запрос не требует высокой консистентности, т.к. не ожидается сразу после создания заказа и задержка обновления не имеет существенного влияния. |
| Отображение статуса заказа.                    | Primary   | Операция чтения по идентификатору лёгкая, пользователь не должен получить "Заказ не найден" для только что созданного заказа.                  |

Допустимая задержка репликации: 30 секунд

Коллекция **products**

| Операция                                                  | Узел      | Обоснование                                                                                                          |
|-----------------------------------------------------------|-----------|----------------------------------------------------------------------------------------------------------------------|
| Поиск товаров по категориям и фильтрация по диапазону цен | Secondary | Запрос не требует высокой консистентности, т.к. задержка обновления не имеет существенного влияния.                  |
| Описание товара на странице продукта                      | Secondary | Запрос не требует высокой консистентности, т.к. задержка обновления не имеет существенного влияния.                  |
| Отображение товара при просмотре корзины                  | Primary   | Во время просмотра корзины требуется подсчитать наличие и цену без ошибок из-за задержки, наличие обновляется часто. |

Допустимая задержка репликации: 1 минута

Коллекция **carts**

| Операция                                 | Узел     | Обоснование                                                                                                              |
|------------------------------------------|----------|--------------------------------------------------------------------------------------------------------------------------|
| Получение текущей корзины                | Primary  | Ожидается, что запрос корзины будет происходить параллельно/сразу после её обновления, потому требуется read-your-writes |
