### <a name="_3bfxc9a45514"></a>**Контекст**

«Мобильный мир» хранит информацию о заказах, товарах и корзинах в трёх коллекциях в MongoDB.

Коллекция **orders**:
```mongodb-json
{
    "_id": ObjectId, 
    "user_id": String, 
    "order_date": Date, 
    "items" : [{
        "product_id": ObjectId,
        "price": Integer
    }], 
    "status": String, 
    "total_price": Integer,
    "geo_zone": String,
}
```
Основные операции:
- Быстрое создание заказов с одновременным списанием остатков.
- Поиск истории заказов конкретного пользователя.
- Отображение статуса заказа.


Коллекция **products**:
```mongodb-json
{
    "_id": ObjectId, 
    "display_name": String,
    "category": String,
    "price": Integer, 
    "stock" : [{
        "geo_zone": String,
        "quantity": Integer
    }], 
    "attributes": JSONB
}
```
Основные операции:
- Частые обновления остатков при покупках.
- Поиск товаров по категориям и фильтрация по диапазону цен.
- Описание товара на странице продукта.


Коллекция **carts**:
```mongodb-json
{
    "_id": ObjectId, 
    "user_id": String,
    "session_id": String,
    "items": [{ "product_id": ObjectId, "quantity": Integer }],
    "status": String,
    "created_at": Date,
    "updated_at": Date,
    "expires_at": Date
}
```
Основные операции:
- Создание корзины, когда заходит гость или новый пользователь.
- Получение текущей корзины по фильтру { session_id, status:"active" } или { user_id, status:"active" }.
- Добавление или замена товара в корзине.
- Удаление товара из корзины.
- Слияние гостевой корзины в пользовательскую, если пользователь залогинится:
  - прочитать гостевую { session_id, status:"active" };
  - добавить её items в корзину { user_id, status:"active" };
  - отметить гостевую как abandoned.
- Отметка корзины как заказанной.

### <a name="_qmphm5d6rvi3"></a>**Решение**

Коллекция **orders**: {user_id: hashed}
- Ключ: user_id позволит держать шарды сбалансированными и эффективно обслуживать запросы истории заказов пользователя.
- Cтратегия: Хэшированное шардирование для сбалансированных шардов. Не требуются запросы по диапазонам.
- Команда: sh.shardCollection("db.orders", { "_user_id" : "hashed" } );
- В дополнение к этому можно использовать Геошардинг, но нельзя использовать только его, т.к. шарды не будут сбалансированными.


Коллекция **products**: {category: hashed}
- Ключ: category позволит эффективно обслуживать поиск внутри категории или для отдельных записей.
- Cтратегия: Хэшированное шардирование для сбалансированных шардов. Не требуются запросы по диапазонам категорий, а только внутри категории.
- Команда: sh.shardCollection("db.products", { "category" : "hashed" } );

Коллекция **carts**: {user_id: hashed, session_id: hashed}
- Ключ: составной ключ (user_id, session_id) позволит держать шарды сбалансированными и эффективно обслуживать запросы по конкретным user_id/session_id.
- Cтратегия: Хэшированное шардирование для сбалансированных шардов. Не требуются запросы по диапазонам.
- Команда: sh.shardCollection("db.products", { "user_id" : "hashed", "session_id" : "hashed" } );

### <a name="_bjrr7veeh80c"></a>**Последствия**

Коллекция **orders**:
- Операции с указанием конкретного user_id будут выполены 1 шардом.

Коллекция **products**:
- Поиск внутри категории будут выполнены 1 шардом. 
- Поиск вне категории будут требовать всех шарды.
- Размеры и нагрузка шардов зависят от размеров и популярности категорий, что может быть помешать оптимальному распределению.  

Коллекция **carts**:
- Операции с указанием конкретных user_id или session_id будут выполены 1 шардом.
